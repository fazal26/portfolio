Prologis.

A real-estate management platform covering sale, rental and lease operations — with logistics, measurements and legal-compliance modules, and an accessibility-first UI delivered to WCAG standards.

RoleLead Engineer
SectorReal Estate
FocusAccessibility
StandardWCAG

Problem

// 01

Real-estate operations do not fit one workflow. A property moving through sale behaves differently from one under lease, which behaves differently again from a rental turnover — and each carries its own logistics, its own measurements, and its own legal paperwork that has to be right.

Teams were running those three tracks across separate tools, re-entering the same property data into each, and reconciling the differences by hand. The measurements that drive pricing lived apart from the compliance documents that depend on them.

One property record. Three operational tracks. Compliance that travels with the data instead of chasing it.

Approach

// 02
  • 01
    Accessibility first, not lastThe interface was built to WCAG standards from the first component rather than audited at the end. Semantic structure, keyboard operability and focus management were acceptance criteria on every ticket, which is considerably cheaper than retrofitting them.
  • 02
    One property model, three tracksModelled sale, rental and lease as operations over a shared property record rather than as separate entities, so measurements and compliance state stay attached to the property wherever it goes.
  • 03
    GraphQL for a wide read surfaceProperty views pull deeply nested, differently shaped data per track. A GraphQL layer let each view request exactly its shape without a proliferation of bespoke endpoints.
  • 04
    Measurements as first-class dataMeasurement modules feed pricing and legal documents directly, so the numbers in a contract are the numbers in the record — not a copy that drifted.
  • 05
    Compliance built into the flowLegal-compliance checks sit inside the operational flow rather than beside it, surfacing what a property still needs before it can progress.

Stack

// 03
React
Node.js
GraphQL
WCAG

Outcome

// 04

Sale, rental and lease operations run against one property record, with logistics, measurements and legal compliance handled inside the same platform rather than reconciled across tools afterwards.

The accessibility work is the part worth naming. Building to WCAG standards from the start meant keyboard operability and semantic structure were design constraints rather than defect reports — a discipline most frontend work never has to acquire.
